## Problem Statement

Every year, thousands of deserving students in India lose access to education because scholarship money never reaches them. Traditional scholarship systems rely on banks, NGOs, and government portals, and each layer adds delays, fees, and opportunities for funds to go missing. A donor has no reliable way to verify that their money actually reached the student.

## Solution

ScholarChain is a peer to peer scholarship funding platform built on the Stellar blockchain. Students connect a wallet and post a funding request directly. Donors browse open requests and send XLM straight to the student's wallet, with no middlemen, no treasury, and no approval gate in between. Every transaction is permanent, public, and verifiable on Stellar Explorer within seconds.

## How It Works

**For Students**
1. Connect a Freighter wallet, set to Testnet.
2. Open the Student Portal and create a pool describing what the funding is for.
3. Set a goal in XLM and a deadline between 1 and 30 days.
4. Donors send XLM directly to the pool. Track progress in the Active, Funded, and Expired tabs.

**For Donors**
1. Connect a Freighter wallet.
2. Open the Donor Portal and browse open pools, filterable by field.
3. Choose a pool, enter an amount, and sign with Freighter.
4. The transaction confirms on Stellar Testnet in seconds, with the hash available to copy or verify on Stellar Explorer.

## Smart Contracts

ScholarChain runs on Soroban smart contracts written in Rust.

- **RequestPool** (`contracts/request_pool`) is the active contract behind the current Student and Donor portals. It stores each funding request on-chain (student, purpose, field, goal, amount raised, expiry) and exposes `post_request`, `record_donation`, `get_request`, `get_count`, and `is_funded`, with events published on every post and donation.
- **ScholarshipFund** and **ScholarshipRegistry** (`contracts/scholarship_fund`, `contracts/registry`) are the original pair of contracts built to demonstrate inter-contract communication for scholarship creation and donation tracking, and remain deployed on testnet as shown in the Contract Information section above.

### Deploy to Testnet

```bash
# Build and deploy the request pool contract
stellar contract build --package request-pool
stellar contract deploy \
  --wasm target/wasm32-unknown-unknown/release/request_pool.wasm \
  --network testnet --source deployer
```

## Features

- Landing page with hero section, live activity strip, and a How It Works section for both roles
- Role-based portals: Student and Donor, fully open with no admin gate
- Student Portal: post a request with an expiry timer, view my requests, track received payments
- Donor Portal: browse all requests, filter by field, sort, search by keyword, fund with a live transaction hash
- Separate tabs for active, funded, and expired pools in both portals
- Direct peer-to-peer payments, XLM goes straight from the donor's wallet to the student's wallet
- One-click copy of the transaction hash on every transaction display
- Live overfunding validation with an on-screen warning and a disabled send button
- Light and dark theme toggle backed by CSS custom properties
- Persistent footer across every page
- Real-time activity strip polling Stellar Horizon
- Toast notifications on successful requests and donations
- Mobile responsive layout down to small screens
- CI/CD pipeline via GitHub Actions
- Vercel Analytics integration
- 20 passing tests across 3 test files
- Soroban smart contracts deployed on Stellar Testnet

## Getting Started

### Prerequisites

- Node.js 20+
- [Freighter Wallet](https://www.freighter.app/) browser extension, set to **Testnet**

### Installation

```bash
git clone https://github.com/shakshi-06/stellar-scholarship-fund.git
cd stellar-scholarship-fund
npm install
npm run dev
```

Open `http://localhost:5173`

### Get Test XLM

Click **Get Test XLM** in the navbar after connecting. This uses Stellar Friendbot to fund your testnet wallet.
